🏥 Electronic Health Record Management System

📌 About Project

This project is a Healthcare Management System that helps patients and doctors manage medical records efficiently. Patients can upload reports and book appointments, while doctors can review reports and provide medical summaries.

✨ Features

  • Upload Medical Reports
  • Doctor Summary & Diagnosis
  • Appointment Booking System
  • Patient & Doctor Dashboards
  • Secure Data Management

💻 Technologies Used

  • Python (Flask)
  • SQLite Database
  • HTML, CSS, Bootstrap
  • OCR Processing, Rule Based Analysis

🎯 Objective

The main objective of this system is to digitalize healthcare services, improve patient-doctor interaction, and provide quick access to medical records.
